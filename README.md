В системах телеуправляемых подводных аппаратов гидродинамическое сопротивление троса, соединяющего аппарат с надводным судном, представляет собой ключевой компонент полного сопротивления системы.
В инженерной практике часто применяется метод, основанный на интегрировании системы нелинейных обыкновенных дифференциальных уравнений.
Другой вариант для нахождения равновесной формы кабеля - использование дискретной, или конечномерной, модели.
В данной работе предлагается воспользоваться упрощенной методикой расчета, реализованной на основе конечномерной модели с применением языка программирования Python.
Излагаемый алгоритм расчета в первую очередь применим для решения плоской задачи, но также он был адаптирован и для определения пространственной конфигурации кабеля.

В качестве исходных данных для выполнения расчета выступают следующие переменные: 
	x_нпа,y_нпа -  координаты заданной позиции НПА относительно судна;
	v_x- скорость движения системы «кабель –НПА» относительно воды, в качестве которой может выступать скорость   подводного   течения v_ТЕЧ или скорость совместного движения судна и НПА; 
	l_k,d_k,w_k,L_k - длина, диаметр звена кабеля, погонная плавучесть кабеля, общая длина кабеля; 
	c_x,S,W_нпa - коэффициент лобового сопротивления, характерная площадь и плавучесть НПА.

Алгоритм прописан специально для буксируемого необитаемого аппарата "Видеомодуль".

### Как запустить
1. Установите Python 3.x.
2. Запустите файл `Videomodul.py`: `python Videomodul.py`.
3. Введите исходные данные, которые запросит программа.
